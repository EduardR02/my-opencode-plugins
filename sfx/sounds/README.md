# Custom Sounds

Drop your custom sound files here. Supported formats: `.mp3`, `.wav`, `.m4a`, `.aiff`.

## Current sounds

| File | Event | Source |
|------|-------|--------|
| `idle.mp3` | Agent idle — "I'm done, your turn" | Civ 6 tech research complete |
| `error.mp3` | Session error | GTA 5 "Wasted" |
| `test-fail.mp3` | Test failure detected | Custom (trimmed to 3s with fade) |

## Adding your own

Replace any file with your own sound. The plugin picks up the path from `opencode.jsonc`. Supported by all three players (macOS afplay, Linux paplay/aplay, Windows PowerShell).
